# 운Pick 브랜드 가이드

> **오늘의 운, 하나만 Pick!**

## 이름
- **운픽** (영문 운Pick, 도메인 woonpick). 오늘의 운을 하나 뽑는다는 뜻이에요.
- 매일 열어 하나를 뽑고, 친구에게 "오늘 내 운픽 뭐 나왔어?" 하고 나누는 습관을 이름에 담았어요.
- 표기: 로고·화면은 `운픽`. 슬로건 `오늘, 나에게 딱 맞는 운`
- 스토어 이름: `운픽 - 오늘, 나에게 딱 맞는 운`

## 핵심 카피 (`src/content/copy.ts`)
| 카피 | 쓰는 곳 |
|---|---|
| 오늘의 운, 하나만 Pick! | 슬로건 · 스플래시 · 스토어 이름 |
| 오늘, 어떤 운을 PICK하시겠어요? | 로그인 · 온보딩 첫 장 · 아침 알림 |
| 사주부터 MBTI까지, 오늘의 나를 PICK하다. | 로그인 · 온보딩 · 스토어 부제 |
| 네 가지 관점으로 고른, 오늘 나에게 맞는 운 | 운세 탭 |
| 궁금한 운만 골라서 PICK | 콘텐츠 탭 |
| 친구의 운도 PICK해 볼까요? | 무료 콘텐츠 · 공유 블록 |
| 더 깊이 알고 싶은 운, 하나 더 PICK | 유료 추천 |
| 내일도 하나 PICK하러 와요 | 홈 맨 아래 |

'PICK'은 고르는 동작을 강조할 때 대문자로, 브랜드명은 `운Pick`으로 써요. 카피에도 이모지는 쓰지 않아요.

## 로고 — 확정 시안 이미지 그대로 (`assets/brand/logo.png`, 876×448)
- 받은 시안 파일을 **그대로** 쓴다. 다시 그리거나 색 · 모양 · 비율을 바꾸지 않는다.
- 앱: `BrandMark`가 이 이미지를 높이(size)에 맞춰 보여주고 모서리만 둥글게 자른다(홈 머리 · 로그인 · 결과 카드 · 공유 카드).
- 스플래시(`assets/splash-icon.png`)와 `docs/wordmark.png`도 같은 원본으로 만든다(`npm run icons`).
- 앱 아이콘 · 파비콘 · 로딩처럼 작은 자리는 운알이(`LogoMark`).

## 캐릭터 · 운알이
- 하루에 좋은 운을 골라 주는 작은 운의 씨앗. 몽글한 몸(파스텔 메시 그라데이션) + 동그란 눈 (`src/components/Mascot.tsx`).
- 색 5가지(classic · pink · peach · mint · lavender) × 표정 6가지(open · wink · happy · sleepy · look · curious) × 소품(sparkle · heart · clover · question · music · headphones).
- 등장 자리: 홈 말풍선 아래 · 4가지 관점 카드 · 검정 홍보 카드 · 무료 콘텐츠 · 결과 카드 · 상세 머리 · 로그인 · 로딩 · 공유 카드 · 앱 아이콘.
- 로고: 굵은 둥근 레터링 '운픽'(획 14) + 오른쪽 위 운알이 물방울 (`BrandMark.tsx`, `npm run icons`).

## 서체
- **Pretendard 한 서체** — 큰 숫자도 굵은 Pretendard.
- **글자 크기는 여섯 단계만** (`src/theme/typography.ts`의 `type` · `txt`)
  | 이름 | 크기/줄간격 · 굵기 | 쓰임 |
  |---|---|---|
  | 큰 숫자 `display` | 40/46 · 800 | 점수 · 큰 숫자 |
  | 제목 `title` | 24/32 · 800 | 화면 제목 · 히어로 제목 |
  | 소제목 `h2`·`h3` | 18/26 · 700 | 섹션 제목 · 카드 제목 · 요약 문장 |
  | 본문 `body` | 15/23 · 400~700 | 본문 · 목록 · 버튼 |
  | 보조 `small` | 13/19 · 500 | 설명 · 라벨 · 날짜 |
  | 작은 글 `micro`·`eyebrow` | 11/15 · 600~700 | 배지 · 영문 눈썹 · 탭바 |
  - 예외는 입력창 16(iOS 확대 방지) 하나뿐. 위계는 크기를 늘리지 말고 굵기와 색으로 만든다.
- **화면 짜임**: 맨 위 카드는 `HeroCard`(그라데이션 · 반경 26 · 여백 22), 홍보 카드는 `PromoCard`, 섹션은 `SectionHeader`/`SubHead`(위 32 · 아래 12), 일반 카드는 `Card`(여백 20)만 쓴다.
- 코드: `src/theme/typography.ts` — `fonts.display`(제목) · `fonts.serif`(예전 강조 자리, 지금은 굵은 Pretendard) · `sansW(굵기)`(본문). 네이티브는 굵기별 파일(`assets/fonts`)
- 라이선스: SIL Open Font License (`assets/fonts/LICENSE-Pretendard.txt`)
- 한자는 파스텔 아이콘 칸 안의 표식으로만 써요(緣 연애, 財 재물, 業 직장, 人 관계).

## 말투 (AI 같지 않게)
- 친구에게 말하듯 짧게. 공유 문구는 반말: "나 전생에 '발해의 서당 훈장'이었대. 너는?"
- **이모지를 쓰지 않아요.** "AI가 분석한", "엔진" 같은 말도 화면에 쓰지 않아요.
- 단정하지 않아요. "~하기 좋은 흐름이에요". 중요한 결정은 전문가 상담을 권해요.
- 숫자로 말해요: 점수, 달, 요일, 날짜.

## 화면 모드
- 마이 > 화면 모드에서 시스템 · 라이트 · 다크를 골라요. 모든 화면이 두 팔레트를 함께 지원해요(공유 카드는 항상 밝은 파스텔).

## 화면 디자인 원칙 — 운알이
- 머리: 모든 화면 "‹ 제목" 왼쪽 정렬 한 줄 + 오른쪽 코인·저장.
- 운세 탭: 하늘 카드(구름 위 운알이 · 주간은 두 마리) + 점수 링 + 흐름 · 집중 테마 → 분야 카드(흰 아이콘 칸 · 최고 배지 · 펼치기) → 흐름 차트 → 네 관점 → 검정 추천 카드.
- 상담: 오늘의 기운 카드 → 파란 테두리 입력 → 알약 칩(선택은 검정 ✓) → 검정 버튼 → '이런 고민도 괜찮아요' 예시.
- 홈: 말풍선(점수 + 한 줄) → 운알이 → 분야 원형 게이지 4개 → '오늘의 운세' 회색 카드 → 행동 → 흐름 보기 → 검정 상담 카드 → 무료로 즐기기 → 4가지 관점 색 카드 → 더 깊이 보기.
- 섹션 제목은 "제목 | 설명   >" 한 줄(`SectionHeader`).
- 맨 위 카드는 `HeroCard`(하늘 그라데이션 + 운알이), 유료 화면 `Hero`도 같은 모양(가로 배치 카드는 운알이 생략).
- 홍보는 `PromoCard`(검정 · 연두 제목 · 흰 알약 · 운알이), 결과 카드는 `darkSurface`(검정 · 흰 글자 · 연두 포인트 · 운알이).

## 공유 카드
- 9:16(1080×1920) 밝은 파스텔 단일 테마. 로고와 날짜 알약, 흰 카드 안에 코랄 눈썹·굵은 제목·아이콘 칸·숫자 칸·잠긴 이야기, 질문과 검정 알약으로 마무리.
- 개인정보(생년월일, 고민 원문)는 넣지 않아요.
