# 한장 브랜드 가이드

> **매일 한 장, 나를 읽다**

## 이름
- **한장** (영문 HANJANG). 하루에 한 장씩 넘기는 일력(日曆)에서 왔어요.
- 매일 아침 오늘의 한 장을 넘기고, 결과도 한 장의 카드로 나눈다는 서비스 구조와 이름이 같아요.
- 표기: 앱·스토어·공유 문구 모두 `한장`이에요. 띄어 쓴 `한 장`은 일반 명사로 쓸 때만 써요(예: "오늘의 한 장").

## 로고
| 요소 | 설명 |
|---|---|
| 마크 | 일력 한 장: 붉은 철끈 띠와 구멍 두 개, 뜯는 점선, 명조체 **한**, 살짝 들린 아래 모서리, 뒤에 겹친 다음 장 |
| 워드마크 | Hahmlet ExtraBold `한장`, 자간 -2% |
| 앱 아이콘 | 남색(#22293F) 바탕 + 일력 마크 (`assets/icon.png`) |
| 코드 | `src/components/BrandMark.tsx`의 `LogoMark` · `BrandMark`. 아이콘은 `npm run icons`로 같은 도형에서 다시 만들 수 있어요. |

- 마크는 기울여도 되지만 -6°~+4° 안에서만 써요(손으로 놓은 종이 느낌).
- 쓰지 않는 것: 초승달·별·반짝이(✦)·보라 그라데이션. 예전 디자인이고 흔한 "AI 운세" 이미지와 겹쳐요.

## 색
| 이름 | 값 | 쓰임 |
|---|---|---|
| 먹남색 | `#22293F` | 글자 강조, 버튼, 앱 아이콘 바탕 |
| 한지 | `#F3EEE4` / 카드 `#F4EDDF` | 화면 바탕, 공유 카드 |
| 낙관 주홍 | `#B5432E` | 도장, 철끈 띠, 강조 한 곳 |
| 달빛 금 | `#D9B872` | 어두운 바탕 위 숫자·포인트 |
| 먹 | `#1C1A17` | 본문 |

규칙: 한 화면에서 주홍은 한 곳만 써요. 그라데이션과 빛 번짐(글로우)은 쓰지 않아요.

## 서체
- 제목·숫자: **Hahmlet**(명조)
- 본문: **IBM Plex Sans KR**
- 한자는 장식이 아니라 표식으로만 써요(緣 연애, 財 재물, 業 직장, 人 관계, 封 잠금).

## 말투 (AI 같지 않게)
- 친구에게 말하듯 짧게 써요. 공유 문구는 반말로 써요: "나 전생에 '발해의 서당 훈장'이었대. 너는?"
- **이모지를 쓰지 않아요.** 문장 끝 장식 기호(✨🔮🌙 등)도 쓰지 않아요.
- "AI가 분석한", "엔진", "알고리즘" 같은 말은 화면에 쓰지 않아요. 대신 "사주 · 태국 점성술 · MBTI · 혈액형을 겹쳐 읽은 풀이"라고 써요.
- 단정하지 않아요. "~할 거예요" 대신 "~하기 좋은 흐름이에요"라고 써요. 중요한 결정은 전문가 상담을 권해요.
- 숫자로 말해요: 점수, 달, 요일, 날짜. 막연한 칭찬은 쓰지 않아요.

## 공유 카드
- 9:16(1080×1920), 한지 단일 테마예요.
- 구성: 제호 `한장 日曆` + `第 N 張`(올해 몇 번째 장) · 이중 테두리와 꺾쇠 · 낙관 · 숫자 칸 · 봉인된 이야기 · 질문형 마무리
- 개인정보(생년월일, 고민 원문)는 카드에 넣지 않아요.
