# WHO AM I? 브랜드 가이드

> **나는 어떤 사람일까**

## 이름
- **WHO AM I?** — "나는 누구인가"라는 질문 자체가 이름이에요. 내가 누구인지, 어떤 사람인지 알아가는 서비스 주제와 같아요.
- 표기: 항상 대문자와 물음표 `WHO AM I?`로 써요. 워드마크에서는 물음표 자리에 로고 마크를 넣어요.
- **한글 표기 '후엠아이'는 쓰지 않아요.** 국내 앱스토어에 같은 이름의 다른 앱(후미글로벌의 리워드 앱)이 있어요.
- 스토어 이름은 중복을 피해 `WHO AM I? - 사주로 읽는 나`로 써요.

## 로고
| 요소 | 설명 |
|---|---|
| 마크 | 직접 그린 물음표 + 점 자리의 붉은 낙관 **我**(나 아). "나는 누구인가?"라는 질문에 사주가 도장을 찍어 답한다는 뜻 |
| 워드마크 | Hahmlet ExtraBold `WHO AM I` + 마크(물음표) |
| 앱 아이콘 | 먹남색(#22293F) 바탕 + 한지색 물음표 + 주홍 낙관 (`assets/icon.png`) |
| 코드 | `src/components/BrandMark.tsx`의 `LogoMark`(fg로 물음표 색 지정) · `BrandMark`. 아이콘은 `npm run icons`로 다시 만들 수 있어요. |

- 밝은 바탕에는 먹남색 물음표, 어두운 바탕에는 한지색 물음표를 써요. 낙관은 항상 주홍이에요.
- 쓰지 않는 것: 초승달·별·반짝이(✦)·보라 그라데이션·네온. 흔한 "AI 운세" 이미지와 겹쳐요.

## 색
| 이름 | 값 | 쓰임 |
|---|---|---|
| 먹남색 | `#22293F` | 글자 강조, 버튼, 앱 아이콘 바탕 |
| 한지 | `#F3EEE4` / 카드 `#F4EDDF` | 화면 바탕, 공유 카드 |
| 낙관 주홍 | `#B5432E` | 도장, 강조 한 곳 |
| 달빛 금 | `#D9B872` | 어두운 바탕 위 숫자·포인트 |
| 먹 | `#1C1A17` | 본문 |

규칙: 한 화면에서 주홍은 한 곳만 써요. 그라데이션과 빛 번짐은 쓰지 않아요.

## 서체
- 제목·숫자·워드마크: **Hahmlet**(명조)
- 본문: **IBM Plex Sans KR**
- 한자는 표식으로만 써요(我 나, 緣 연애, 財 재물, 業 직장, 人 관계, 封 잠금).

## 말투 (AI 같지 않게)
- 친구에게 묻듯 짧게 써요. 질문형이 브랜드의 목소리예요: "너는 전생에 누구였을 것 같아?"
- **이모지를 쓰지 않아요.** 문장 끝 장식 기호도 쓰지 않아요.
- "AI가 분석한", "엔진", "알고리즘" 같은 말은 화면에 쓰지 않아요.
- 단정하지 않아요. "~하기 좋은 흐름이에요"라고 쓰고, 중요한 결정은 전문가 상담을 권해요.
- 숫자로 말해요: 점수, 달, 요일, 날짜.

## 공유 카드
- 9:16(1080×1920), 한지 단일 테마예요.
- 구성: 제호 `WHO AM I?` + `第 N 號` · 이중 테두리와 꺾쇠 · 낙관 · 숫자 칸 · 봉인된 이야기 · 질문형 마무리
- 개인정보(생년월일, 고민 원문)는 카드에 넣지 않아요.
